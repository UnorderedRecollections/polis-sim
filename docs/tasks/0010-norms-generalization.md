## Description

Norms *seem* universal (every jurisdiction has rules in force), but this
needs documentation, not assumption. Write a design document examining how
/if the Norm concept (rule_form × resource × property × beneficiaries ×
source: custom|statute) generalizes across the existing jurisdictions:

- which jurisdictions have norms over *resources* (fisheries, land-commons)
  vs. norms over *conduct/status* (criminal, citizenship, contract);
- how beneficiaries/holders read in non-resource jurisdictions;
- how a norm's source lifecycle (custom → statute → superseded → repealed)
  maps onto the machinery everywhere;
- what changes, if anything, the Norm model needs to be truly universal.

Deliverable: `docs/design/norms-generalization.md`.

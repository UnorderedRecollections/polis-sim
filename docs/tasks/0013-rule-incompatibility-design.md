## Description

Dispute generation needs the **rule incompatibility relation**: which
rule_forms cannot coexist over the same resource property. Write a design
document covering:

- the shape of the relation (symmetric pairs? property-scoped? degrees:
  strict incompatibility vs. tension vs. hierarchical override);
- whether incompatibilities are declared per jurisdiction, derived from
  rule-form semantics, or both;
- how an incompatibility becomes a *legal question* (the dispute's core),
  and how that question maps to the procedural path (petition → competing
  bills → Council or archivist decision);
- worked incompatibilities for the backed jurisdictions plus fisheries.

Deliverable: `docs/design/rule-incompatibility.md`.

# 0009: Taxonomy of requirements across all jurisdictions

- **created:** 2026-09-08T18:50:45Z
- **type:** [simulation]
- **depends-on:** 0007
- **status:** open

## Description

Build a taxonomy of requirements for **all fifteen jurisdictions**: which
data-model concepts each jurisdiction actually needs. Open question flagged
by the user: does the concept of **holdings** apply to all jurisdictions
(e.g. does "holding" mean anything in criminal law or foreign relations —
or is it resource-jurisdiction specific)?

For each jurisdiction, classify:

- whether resources/holdings apply, and in what sense;
- which activity signatures are meaningful;
- which rule forms and incompatibilities are natural;
- what "facts on the ground" look like there.

Deliverable: design document with a per-jurisdiction requirements matrix
(marking universal vs. resource-jurisdiction-only concepts), so the data
model grows honestly rather than forcing every jurisdiction into the
fisheries shape.

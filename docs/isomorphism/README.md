# The Isomorphism — documentation

The project's thesis: **a git repository is the historical/legal-record layer
of a legal order; a GitHub-like platform is the constitutional/institutional
apparatus governing how the corpus may change.**

## Reading order

1. **[synopsis.md](synopsis.md)** — the canonical conceptual skeleton
   (§1–§21). Code comments cite these section numbers; treat this file as the
   source of truth for terminology.
2. **[the-archive.md](the-archive.md)** — git as legal memory: corpus,
   commits, tags; the geography of clones, remotes and forks.
3. **[lines-of-development.md](lines-of-development.md)** — branches, merges
   and the life of legal history: reconciliation, codification, repeal,
   transplants, reconstruction, replacement.
4. **[institutions.md](institutions.md)** — the platform as constitutional
   apparatus: petitions, scrutiny, jurisdiction, entrenchment, and the
   Mechanical Magistrate (CI).
5. **[the-three-stores.md](the-three-stores.md)** — the project's ontology:
   git history / civil registry / matter store; recording vs. enforcing;
   the two clocks.
6. **[phases.md](phases.md)** — the two eras: customary machinery (gogs)
   → codified machinery (gitea + CI), and how the transition is itself
   enacted through the old machinery.
7. **[political-economy.md](political-economy.md)** — three layers: material
   substrate, knowledge commons, institutional layer.
